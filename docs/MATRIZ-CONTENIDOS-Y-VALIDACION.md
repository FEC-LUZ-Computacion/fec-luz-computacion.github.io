## Orden recomendado de carga

1. **El Departamento y Pregrado:** cotejar los datos ya suministrados con los reglamentos y el documento curricular; registrar aparte lo que aún requiera confirmación.
2. **Cuerpo Docente:** completar el formulario, verificar los datos y obtener autorización para publicar cada ficha.
3. **Investigación, Extensión y Postgrado:** incorporar programas y resultados vigentes con enlaces o documentos de respaldo.
4. **Actualidad, Contacto e identidad visual:** agregar información autorizada y actualizada.

La revisión de diseño visual definitivo y la publicación pertenecen a la Fase 2. Mientras se completa esta matriz, mantener abierto el PR y no fusionarlo ni cambiar la configuración de GitHub Pages.
